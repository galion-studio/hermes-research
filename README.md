# Hermes Research

The open research line of [Galion Studio](https://galion.studio).

Hermes Research is a small agent that uses a model running on your own computer. The agent can search, read, write, and send one helper when you ask for one. It does not call a cloud model when your computer is off.

This repository is the public face of that research. The private desk stays private.

License: MIT.

## What it is

- One brain, on the operator's machine.
- One harness, which does the jobs.
- A helper only when the request asked for a helper.
- A closed line ends the turn in one sentence. It does not wait for minutes, and it does not switch brains.

## What it is not

- Not the Galion product.
- Not Merlin.
- Not a promise of a higher exam score. The model you run is the knowledge. This repo does not pretend a prompt is a degree.
