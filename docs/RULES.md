# Rules

These apply to every research session.

1. The brain is the model on the operator's computer. Tools and helpers run beside the data. If that computer is not answering, the turn ends. The sentence names the address that refused. There is no cloud substitute and no long wait. A single blink gets one more try, one second later.

2. A helper runs only when the person asked for one. The request has to say so, in plain words such as "one task" or "use a helper". "Remember this word" is not a request for a helper. The agent answers that itself.

3. When a helper is sent, the agent stops and waits. It does not guess the helper's result. The result arrives as the next message.

4. If a helper was told to print one value, and the print is the answer, the helper stops. It does not keep calling tools to rephrase a number it already printed.

5. A wrong score is written down. A lucky sentence is not a win.
