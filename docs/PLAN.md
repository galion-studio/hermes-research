# Plan

Written 7 October 2026. The prototype works. It is not finished.

## Already true

- The line between the laptop and the agent comes back after a restart.
- The agent can answer, search, save a file, read it back, and wait for a helper instead of guessing.
- A helper that is asked to add two numbers prints the sum and stops.
- A dead line ends the turn quickly.

## Fixed with this cut

- A simple request no longer starts a helper. "Remember this word" is answered in the same conversation.
- A one-second blink of the laptop gets one more try before the turn is declared dead.

## Not this cut

- No new product.
- No second connection method.
- No training run. Higher math and physics scores come from measuring the laptop model and writing the misses down, then changing only what the misses prove. A prompt is not a curriculum.
